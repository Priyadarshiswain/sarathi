Data reliability notes

Every field on this page is copied verbatim from your own memory files and steering decisions — nothing here is written or paraphrased by the model. Module placement is a fixed rule based on each entry's own type value; an entry's raw type is shown on its card whenever it differs from its module's native type. The simple/verbose toggle and each row's independent expand only change which already-present fields are currently visible — nothing is fetched or composed when you switch views.
